# Trazabilidad vigente del proyecto

Los requerimientos generales aprobados se mantienen en:

- [`docs/chapter3/ENTREGA_01_REQUISITOS.md`](../chapter3/ENTREGA_01_REQUISITOS.md), apartado **3.1 Requerimientos Generales del Sistema**.

Cadena obligatoria:

`Objetivo → alcance → requisito → historia → caso de uso → sprint → código → prueba`

Para mantener un texto académico compacto, los identificadores `RF`, `RNF`, `HU`, `CU` y `CP` se administrarán en la matriz técnica de trazabilidad y en las siguientes entregas. La versión final no podrá marcar cobertura completa mientras existan pruebas fallidas o verificaciones no funcionales pendientes.

Este archivo ya no contiene agentes, skills, pagos ni rol gerente porque no forman parte del alcance implementado.
