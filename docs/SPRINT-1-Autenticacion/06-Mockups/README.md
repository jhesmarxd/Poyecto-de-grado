# Mockups Sprint 1 — Autenticación y Roles

## Herramienta Recomendada
- **Figma** (gratis, colaborativo) — ideal para wireframes
- **Excalidraw** (rápido, estilo hand-drawn) — alternativo
- **IA Generativa** (v0.dev, Galileo AI, Uizard) — para bocetos rápidos, luego refinar manual

## Convenciones
- **Baja fidelidad** (wireframe): cajas, líneas, texto — sin colores finales ni imágenes reales
- **2 versiones por vista**: Desktop (1920×1080) + Mobile (375×667)
- **Anotaciones numeradas** ① ② ③... con leyenda lateral
- **Nomenclatura archivos**: `S1_01_login_desktop.png`, `S1_01_login_mobile.png`, etc.
